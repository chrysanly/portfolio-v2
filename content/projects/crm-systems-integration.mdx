## Problem

The client struggled with fragmented data across four independent platforms, creating operational silos and delayed event tracking.

## Approach

Architected and deployed an interconnected data pipeline linking all four systems into a centralized enterprise CRM.

Developed a highly modular, reusable event registration workflow built to handle rapid marketing campaign scaling securely.

## Stack notes

PHP and Laravel against SQL, with a meaningful share of the logic living in
stored procedures and database functions rather than application code.
