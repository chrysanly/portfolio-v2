## Problem

Modernizing a legacy infrastructure while adding secure, real-time messaging, file uploads, and notification systems without breaking production availability.

## Approach

Developed a highly scalable suite of Laravel applications featuring real-time data sync, encrypted third-party integrations, and automated cloud file handling.

Successfully refactored and modernized a legacy Laravel 5 system to modern standards.

## Stack notes

Laravel and MySQL at the centre. Pusher and Firebase carry the real-time
channels, Twilio handles OTP delivery, Laravel Passport issues OAuth tokens, and
AWS S3 stores uploaded assets.
