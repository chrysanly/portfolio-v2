## Approach

Full-stack Laravel work across several high-performance applications, with
real-time backends on Pusher, Firebase and Twilio.

Integrations covered Google Maps, Monday.com and AWS S3. Legacy Laravel 5 systems
were refactored to current versions alongside API and database performance work.

Authentication used Twilio OTP and Laravel Passport OAuth. A proof-of-concept
facial recognition login with activity logging was also built.

Agile ceremonies were run from this role, and junior developers were mentored
through it.

## Stack notes

Laravel and MySQL at the centre. Pusher and Firebase carry the real-time
channels, Twilio handles OTP delivery, Laravel Passport issues OAuth tokens, and
AWS S3 stores uploaded assets.
